# onato.com

Static personal site: a WebGL cloud shader (`fog-renderer.js`) behind a stack of
`details`/`summary` items in `index.html`, styled by `styles.css`, plus a reading list at
`/reading/` generated by `scripts/build-reading.py` from `data/books.yml` and the Google Books
cache in `data/google-books/`.

## Build

`make build` minifies JS and CSS into `build/`, inlines the stylesheet into `index.html`, stamps
script URLs with a content hash, generates `build/reading/index.html`, and fails if any built file
is over 14 KB (the reading page is allowed 60 KB). `make dev` serves `build/` locally.

## Rules

- Keep the home page to the four requests it makes now; no new scripts, fonts or images.
- The shader must stay still (one frame) under `prefers-reduced-motion` and on software WebGL,
  and the DPR cap of 1.5 stays.
- Text sits over the sky, so check contrast against the fallback body colour too.
- Every book in `data/books.yml` needs a record in `data/google-books/<isbn>.json`. Fix data in
  those files; never normalise or invent author names in code.
- Commit as you go with conventional commits (`feat:`, `fix:`, `perf:`, `chore:`).

## Reviewing pull requests

Judge changes against what matters for this site, and skip style nits and anything `make build`
already enforces:

- Correctness: broken HTML, dead anchors, shader edits that could fail to compile, JavaScript that
  breaks without WebGL or under `prefers-reduced-motion`.
- Weight: the per-file size limits and the home page's request count.
- Accessibility: contrast over the sky and the fallback colour, keyboard access to the stack.
- Data: every `data/books.yml` entry has a cache record and no author is invented.
- Copy: typos and inconsistencies, briefly.
